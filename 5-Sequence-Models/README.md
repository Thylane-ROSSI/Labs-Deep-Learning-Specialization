# Course 5: Sequence Models

✅ **Status: Completed**

This directory contains the core programming assignments and notes for the fifth course of the specialization. These labs focus on sequence modeling with RNNs, LSTMs, and GRUs, natural language processing through word embeddings, sequence-to-sequence architectures with attention, and modern Transformer models.

### Labs Overview

1. **Recurrent Neural Networks (RNN, GRU, LSTM)**
   * **Objective:** Understand how neural networks process sequential data and implement memory cells to overcome vanishing gradients.
   * **Key Concepts:** Recurrent Neural Networks (RNN), Backpropagation Through Time (BPTT), Gated Recurrent Units (GRU), Long Short-Term Memory (LSTM), Bidirectional RNNs.

2. **Natural Language Processing & Word Embeddings**
   * **Objective:** Move beyond one-hot representations to learn dense vector spaces that capture semantic relationships and analogies between words.
   * **Key Concepts:** Word Embeddings, Word2Vec (Skip-gram & Negative Sampling), GloVe, Cosine Similarity, Debiasing Word Embeddings.

3. **Sequence-to-Sequence & Attention Models**
   * **Objective:** Build models capable of translating sequences or generating text/audio using search algorithms and focus mechanisms.
   * **Key Concepts:** Encoder-Decoder Architecture, Beam Search, Attention Mechanism, CTC Cost, Trigger Word Detection.

4. **Transformers**
   * **Objective:** Implement attention-based Transformer models to process sequences in parallel and capture deep contextual dependencies.
   * **Key Concepts:** Self-Attention (Query, Key, Value), Multi-Head Attention, Positional Encoding, Masked Attention.
