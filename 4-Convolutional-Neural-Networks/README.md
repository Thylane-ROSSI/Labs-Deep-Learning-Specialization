# Course 4: Convolutional Neural Networks

✅ **Status: Completed**

This directory contains the core programming assignments for the fourth course of the specialization. These labs focus on how computer vision has evolved, covering foundational CNN layers, deep convolutional architectures, object detection, and special applications.

### Labs Overview

1. **Foundations of Convolutional Neural Networks**
   * **Objective:** Implement the foundational layers of CNNs and stack them properly in a deep network to solve multi-class image classification problems.
   * **Key Concepts:** Pooling, convolutions, multi-class image classification.

2. **Deep Convolutional Models & Transfer Learning**
   * **Objective:** Discover practical methods used in deep CNNs and apply transfer learning to your own network.
   * **Key Concepts:** Residual Networks (ResNets), Transfer Learning with MobileNet.

3. **Object Detection & Image Segmentation**
   * **Objective:** Apply CNNs to visual detection tasks, including challenging fields like autonomous driving.
   * **Key Concepts:** Object detection, car detection, image segmentation using U-Net.

4. **Special Applications: Face Recognition & Neural Style Transfer**
   * **Objective:** Implement algorithms to recognize faces and use neural style transfer to generate art.
   * **Key Concepts:** Face recognition, Neural Style Transfer, art generation.
